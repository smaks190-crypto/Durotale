# DUROTALE — Побег из Дурки (Android)

Ретро-игра в жанре Undertale-adventure / turn-based battle, разработанная на **Kotlin** и **Jetpack Compose**.

## 🎮 Описание игры
Пациент #404 заперт в мягкой одиночной камере №6 психиатрической больницы. Ваша задача — выбраться на свободу, перехитрив санитара Михалыча.

### Концовки:
1. **«Кто в халате — тот и врач» (Основная):**
   Постучите в дверь камеры $\to$ отвлеките санитара Михалыча байкой про выпавший телефон $\to$ одолейте его в пошаговой битве сердечком $\to$ снимите белый халат и заприте Михалыча в камере!
2. **«Овощ» (Секретная):**
   Наберите правильную комбинацию шума у двери: **Тарабанить $\to$ Орать $\to$ Тарабанить $\to$ Тарабанить $\to$ Орать**.

## 🚀 Автоматическая сборка APK на GitHub (GitHub Actions)

В проекте настроен CI/CD workflow: `.github/workflows/build-apk.yml`.

### Как это работает:
1. **При каждом пуше в ветку `main` или `master`:**
   - GitHub Actions автоматически запускает сборку проекта на виртуальной машине Ubuntu.
   - Запускаются unit-тесты.
   - Собирается установочный файл `app-debug.apk`.
   - Готовый APK выгружается в артефакты сборки (**Artifacts**) со сроком хранения 30 дней.
2. **Как скачать собранный APK:**
   - Перейдите в репозитории во вкладку **Actions**.
   - Нажмите на последний выполненный рабочий процесс **Build Android APK**.
   - Внизу страницы в блоке **Artifacts** скачайте архив `durotale-debug-apk`, внутри которого лежит готовый `.apk` для установки на Android-устройство.
3. **Ручной запуск сборки:**
   - Во вкладке **Actions** выберите **Build Android APK** $\to$ нажмите кнопку **Run workflow**.
4. **Создание официального релиза с прикреплённым APK:**
   - Создайте и запушьте тег версии, например `v1.0.0`:
     ```bash
     git tag v1.0.0
     git push origin v1.0.0
     ```
   - GitHub Actions автоматически опубликует новый GitHub Release во вкладке **Releases** с прикреплённым APK-файлом.
