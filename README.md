# Дурка — Сквозняк

Пробная глава психологического хоррор-детектива. Утром медсестра оставляет дверь приоткрытой. В стене у койки кто-то стучит.

## Запуск на Windows x64

Скачайте [Windows x64 — готовая сборка](https://github.com/smaks190-crypto/Durotale/archive/refs/heads/windows-x64-demo.zip). Распакуйте весь ZIP. Откройте **Windows** и дважды щёлкните **Start.cmd**. При первом запуске он восстановит и проверит поставляемый архив, распакует игру рядом с собой и запустит **Durka.exe**. Все компоненты входят в загрузку. При следующих запусках можно открывать **Windows/Game/Durka.exe** напрямую. Держите Durka.pck и каталог data_Durotale_windows_x86_64 рядом с программой.

## Управление

WASD — шаг. Мышь — обзор. E — встать, осмотреть, открыть или постучать. Там, где действие требует удержания, об этом сообщает подпись. Esc открывает паузу. В ней можно изменить чувствительность мыши и по отдельности отключить тряску камеры, мигание и VHS. После финальных титров кнопка «Пройти снова» начинает новое утро.

## Из исходников

Установите Godot **4.6.3 .NET**, .NET SDK **8** и шаблоны экспорта **4.6.3.stable.mono**. Откройте project.godot, соберите C# кнопкой Build и нажмите F6 в сцене Episode.tscn или F5 для запуска проекта. Для экспорта откройте «Проект → Экспорт», выберите **Windows Desktop**, затем «Экспортировать проект» и сохраните Durka.exe в отдельную папку. Используется рендерер OpenGL Compatibility.
