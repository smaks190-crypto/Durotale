# ПАЛАТА №9 · Godot-прототип (v0.2)

Нативный прототип на Godot 4.7.2/GDScript, основанный на предоставленном автором HTML/Canvas-коде **«ПАЛАТА №9 — тихая история о громкой двери»**.

**Авторские механики из HTML-версии:**

- Ночная палата (кровать, дверь, окно, плакат, царапины и записка); перемещение со столкновениями.
- Четыре действия у двери: крик, ожидание, притворство и серия из четырёх ударов.
- Санитар Боря и пошаговый бой: атака с таймингом, действия/разговоры, расходуемые предметы и пощада.
- Сердечко, уклонение от четырёх чередующихся типов опасностей, ОЗ и неуязвимость после получения урона.
- Четыре концовки: человечность, побег, тихий коридор и секретный ромашковый режим.
- Локальное сохранение открытых концовок через `ConfigFile`, настраиваемая сложность, кнопки для Android.

**Ограничения прототипа:** в HTML-оригинале есть уникальная музыка, продвинутые катсцены, детализированные спрайты и анимация печати текста. Они ещё не перенесены. Визуал здесь перерисован средствами Godot; чужие ресурсы не используются. HTML как таковой **не** выполняется внутри Godot.

## Проверки через терминал

```bash
godot --headless --path . --import
godot --headless --path . --script res://tests/smoke_test.gd
godot --headless --path . --export-debug Android build/Palata9-debug.apk
```

На ПК стрелки или WASD — ходить/выбирать, Z или Enter — действие, X — назад. На Android используются сенсорная крестовина и кнопка действия; во время боя сердце управляется той же крестовиной.

Для сборки APK в CI нужны экспортные шаблоны той же версии Godot, Android SDK, JDK17 и отладочный keystore. GitHub Actions выполняет эти шаги автоматически.
