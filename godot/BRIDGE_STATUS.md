# Связка Qwen4-Max → OpenCode → Godot: техническое состояние

Путь на Debian: `/home/droid/projects/experiments/qwen-web-proxy`.

- Версия OpenCode: 2.3.2.
- Авторизация Qwen Chat через Firefox-профиль: ранее проверена (неофициальная интеграция).
- Перед запросом модель фиксировалась в UI как Qwen4-Max; исходящий запрос подтвердил `model=qwen4-max`.
- До начала доработки изображения: текстовый запрос прошёл, создание `hello_qwen.txt` через инструмент OpenCode прошлось успешно.
- Добавлена проверка изображений в Python-прокси: PNG/JPEG/WebP, до 3 МБ на изображение, максимум 3; HTTP URL и произвольные локальные пути отвергаются. Изображения передаются в WebSocket как вложения.
- Добавлено расширение Firefox v1.1.0 с отправкой через `input[type=file]` и ожиданием UI подтверждения загрузки.
- 17 Python unit/security checks прошли; JavaScript синтаксис проходил `node --check`.
- **Сквозной тест изображения не прошёл**: `HTTP 502: Qwen did not confirm the image preview/upload; request was not submitted`. Текстовый запрос без картинки намеренно не отправлялся.
- При последующей проверке DOM Qwen обнаружен скрытый `<input id="filesUpload" type="file">`. Требуется доработка способа загрузки файла через React frontend и повторное тестирование. Браузерный upload может требовать Selenium send_keys вместо синтетического change.
- Затем Debian VM стала недоступной для Desktop Commander; последнее состояние соединения — Offline. Нельзя считать работу через Qwen4-Max или сборку Godot проверенной после этого.

При возобновлении Debian:
1. Проверить `systemctl --user status qwen-web-proxy.service`.
2. Убедиться, что Firefox-профиль использует расширение v1.1.0.
3. Проверить отображение прикреплённого файла на Qwen через реальный браузер, без обходов защит.
4. Только после успешной загрузки пользовательских референсов передать `BRIEF_FOR_QWEN.md` и существующий проект Qwen4-Max через OpenCode.
5. Запустить Godot 4.7.2 headless-проверки и экспорт, а при ошибках фиксировать журналы.

**Не копируйте в Git репозиторий файлы учётных данных Firefox, tokens, `hosts.yml`, приватные профили браузеров.**
