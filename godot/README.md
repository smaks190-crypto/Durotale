# Дурка · Сквозняк

Самостоятельная пробная глава на Godot 4 Standard. Импортируйте project.godot из этой папки и нажмите F5. Локальная версия редактора для проверки — 4.6.3. Все игровые сцены, геометрия, персонажи и код находятся в этой папке. Малые текстурные образцы созданы из концепта заказчика. Геометрия, материалы и звук собираются при запуске.

**Android ARM64.** Распакуйте архив сборки, установите APK и откройте «Дурка · Сквозняк». Двигайте пальцем на левой половине и удерживайте направление. Справа проведите пальцем для обзора. Коснитесь «Рука» для взаимодействия. Значок паузы открывает чувствительность и отдельные выключатели тряски, мигания и плёнки.

**Windows x64.** Распакуйте EXE и PCK вместе. WASD — ходьба, мышь — обзор, E — взаимодействие, Esc — пауза.

**Повторный экспорт.** В Godot установите шаблоны той же версии, что и редактор. В Project → Export выберите Android либо Windows Desktop. Для подписанного отладочного APK в Editor Settings → Export → Android укажите SDK, JDK и debug keystore.

**Проверка прохождения.** После импорта запустите из папки проекта:
```sh
godot --headless --fixed-fps 60 --script tests/route.gd
```
Тест ходит по уровню через контроллер и коллизии, вводит E, проверяет ранний ритм, форточку, три медленных открытия, сохранение и установку ручки, возвращение и обе концовки. При успехе выводится ROUTES_OK.
