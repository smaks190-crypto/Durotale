# Дурка · Палата №0

Пробная глава для Android arm64. Установите DurkaDemo-debug.apk и поверните телефон горизонтально. При запросе Android разрешите установку для приложения, из которого открыли APK. Кнопки слева отвечают за ходьбу, свайп справа за обзор, E за действия и удержание, Ⅱ открывает паузу. Настройки позволяют раздельно выключить тряску, мигание и шум и настроить обзор.

На Windows распакуйте архив целиком и запустите DurkaDemo.exe рядом с DurkaDemo.pck. Управление — WASD, мышь, E и Esc.

Для запуска исходников импортируйте godot/project.godot в Godot 4.6.3 Standard и нажмите F5. Шаблоны экспорта нужны только для сборки. Для Android укажите SDK и JDK в настройках редактора. В Project → Export выберите Android для отладочного APK или Windows Desktop для EXE с отдельным PCK.

## Если потерялись

Свежая простыня и кружка помогут узнать свою палату. У поста можно свернуть в архив или процедурную. Разговор у двери и сквозняк имеют значение. У батареи попробуйте два или больше отдельных ударов и выждите ответ. Вернитесь к форточке, затем проверьте дальнюю дверь. Когда ручка останется в ладони, ищите квадратный стержень. После установки вернитесь в освещённую палату. У финальной двери удерживайте E или уходите к стойке поста и нажмите E.

## Проверки

Из каталога godot выполните команды:

```sh
godot --headless --import
godot --headless --script tests/check_state.gd
godot --headless --fixed-fps 60 --script tests/check_real_controls.gd
```

Вторая проверка охватывает интервалы, медленную и быструю дверь и сохранность предмета. Третья ведёт персонажа через обе концовки с физическими коллизиями, действиями ходьбы и взаимодействия и событиями сенсорного обзора.
