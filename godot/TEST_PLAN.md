# Acceptance checklist / Палата №0

## Автоматические проверки (требуют Godot)

```sh
godot --headless --path . --editor --quit
godot --headless --path . --script res://tests/check_state.gd
```

Ожидается `STATE_TESTS_OK`, без ERROR и PARSE ERROR.

## Ручные сценарии (на настольной или Android-сборке)

- [ ] Появляется палата, пациент виден за плечом, WASD/камера/коллизии работают; у стены камера не проваливается.
- [ ] Медсестра произносит приветствие и исчезает; первые секунды спокойные.
- [ ] Можно вернуться из коридора обратно в палату.
- [ ] Два стука с интервалом 0.8 с вызывают эхо с таким интервалом; визуальная реакция видна без звука.
- [ ] Можно постучать **до** закрытия форточки и **после**, ритм сохраняется.
- [ ] Форточка переводит палату в другую реальность при повороте либо через fallback через 4 сек.
- [ ] Третье медленное открывание дальней двери выдаёт ручку. Два быстрых могут выдать раньше; быстрые действия не обязательны.
- [ ] После получения ручки можно сменить все три реальности, ручка остаётся в кармане.
- [ ] У соседней палаты ручка ставится в замок, барьер убирается.
- [ ] В финале появляются одновременно признаки нескольких состояний.
- [ ] Удержание E у соседней двери 2+ с заканчивается концовкой hold.
- [ ] Выход через пост заканчивается концовкой leave.
- [ ] После концовки можно перезапустить главу.
- [ ] ESC: пауза, чувствительность, выключение тряски, вспышек, VHS.
- [ ] На Android работают экранные кнопки движения, взаимодействие и свайп обзора.
- [ ] Оба финала достижимы с выключенным звуком.
